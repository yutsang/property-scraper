CENTALINE RESIDENTIAL SCRAPER - AREA EXTRACTION FIX
================================================================================

DATE: 2026-01-18
ISSUE: Many entries have empty area fields despite data being visible on page
STATUS: ✅ RESOLVED

================================================================================
WHAT WAS THE PROBLEM?
================================================================================

- 48,029 records (9.4%) had null 'area' field
- Area data IS displayed on the Centaline website HTML table (面積(實) column)
- Scraper only extracted from JavaScript __NUXT__ object
- Some transactions have null nArea/gArea in JavaScript even though HTML shows it

Example from your report:
  Date: 2026-01-18
  Address: Belgravia Place 1期 1A座 中層 1室
  Area: 344呎  ← This was visible but not being extracted

================================================================================
WHAT WAS FIXED?
================================================================================

✅ Added HTML table extraction as fallback
✅ When JavaScript has null area, scraper now falls back to HTML table
✅ HTML table Column 5 (面積(實)) contains the area: "344呎" → 344.0
✅ Added enhanced logging to track fallback usage
✅ Parsing handles all formats: "344呎", "1,234呎", etc.
